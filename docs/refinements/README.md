# Refinement screenshots — historical

These captures are design history from earlier Home/Explore passes. They are
kept for reference, not as the current spec.

The `your-decks-*.png` captures predate the **2026-11-18 flat-folder redesign**
and show the old nested-folder model (for example, a folder reporting
`2 decks · 1 folder`, or a child row under a parent). The current model is one
flat folder list: every folder is a top-level peer, counts cover only decks
filed directly in that folder, and there is no Location/parent picker or parent
breadcrumb. See `README.md` and `docs/design-language.md` for the current spec.

The Explore-sheet/row captures are also historical and are not current UI
contracts.
